## What changed

- Updated default Flash model from `gemini-2.0-flash` to `gemini-2.5-flash` in:
  - `.env.example`
  - `lib/gemini/client.ts` (fallback default)
- Pro model stays at `gemini-2.5-pro` (still GA, no change needed).

## Why

`gemini-2.0-flash` returns **404 Not Found** for new Gemini API users with the message *"This model is no longer available to new users"*. The model still exists for older projects but is gated off for new keys. Per Google's current model list, `gemini-2.5-flash` is GA (released June 2025) and is the stable replacement.

Avoided `gemini-3-flash` (still in preview — same gating risk) and `gemini-3.1-flash-lite` (smaller / cheaper, but quality matters for our match-ranking step).

## Files touched

- `.env.example`
- `lib/gemini/client.ts`

## How to verify

In your `.env`, update line 12:

```diff
- GEMINI_FLASH_MODEL=gemini-2.0-flash
+ GEMINI_FLASH_MODEL=gemini-2.5-flash
```

Then:

```bash

```

Expected: both `Gemini Flash` and `Gemini Pro` print `{ ok: true, echo: 'hello relai' }`.
