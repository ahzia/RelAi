## What changed

- Added `lib/gemini/client.ts` with `callGemini<T>({ model, systemInstruction, userMessage, schema, temperature?, maxRetries? })`:
  - Wraps `@google/generative-ai` with **JSON mode** (`responseMimeType: "application/json"`).
  - Validates output against a Zod schema; one automatic retry on parse/validation failure that includes the broken output + error back to the model.
  - Reads model IDs from `GEMINI_FLASH_MODEL` / `GEMINI_PRO_MODEL` (with sensible defaults).
- Added `lib/gemini/types.ts` with Zod schemas + exported TS types for all 4 prompt outputs from `ARCHITECTURE.md §8`:
  - `ProfileSchema` (extractProfile)
  - `RankMatchesSchema` (rankMatches)
  - `ConversationSchema` (simulateConversation)
  - `MatchSummarySchema` (summarizeMatch)
- Added `scripts/check-gemini.ts` smoke test — calls Flash + Pro with a tiny JSON probe and validates with Zod.
- Added npm shortcuts: `pnpm check:gemini` and `pnpm check:supabase`.

## Why

Unblock the AI track. With these in place, writing a new prompt is just: import schema + write system instruction + call `callGemini`. No SDK research, no JSON parsing, no validation boilerplate per prompt.
