## Tracks (pick what fits your submission tags)

| Track | What judges expect |
|-------|-------------------|
| **Collaborative Systems** *(RelAI primary)* | Multi-agent system: specialized agents coordinate and share information for a goal a single LLM cannot handle alone. |
| **Agentic Workflows** *(RelAI secondary)* | Agent plans steps, calls tools (APIs, DB, browsers), manages multi-step tasks over time. |
| **Intelligent Reasoning** *(RelAI secondary)* | Advanced reasoning; handles roadblocks and replans without constant human intervention. |
| **Enterprise Utility** *(RelAI secondary)* | Solves real friction for managers/entrepreneurs at AI Week (e.g. event networking). |

## Partner requirements (RelAI stack)

### Vultr — backend / deployment

**Challenge:** Web-based enterprise agent deployed on Vultr.

**You must deliver:**

- GitHub repo with setup docs
- **Vultr VM** backend deployment
- **Public demo URL**
- **Recorded demo video**
- Clear architecture + use case explanation

**Tech notes:**

- Any language/framework
- Open-source LLMs + RAG allowed
- **Vultr Serverless Inference** available for eligible projects
- **Vultr GPUs are not available** for this event
- **$200 credits/participant** (up to 300, first-come) — valid **30 days**; link payment method to keep infra after credits expire

**Useful workshops:** Vultr Serverless Inference, Supabase, Coolify, How to redeem Vultr credits

**Resources:** [Vultr setup guide](https://lablab.ai) (from event page), product/platform/support docs, Serverless Inference docs, Coolify + Claude Code on Vultr guide

---

### Google Gemini — AI layer

**Challenge:** Intelligent agents/apps using Gemini + Google AI Studio.

**Project should:**

- Use Gemini (AI Studio or API) for reasoning, chat, or multimodal understanding
- Implement agent-driven workflows responding to user input, data, or context
- Show practical value via working prototype

**Model choice (from RelAI plan):**

- **Gemini Flash** — speed, onboarding, extraction, real-time flows
- **Gemini Pro** — deeper match reasoning, multi-step decisions

**Access:**

- Google AI Studio (no API setup for experiments)
- Gemini API free monthly allowance
- **$300 Google Cloud credits** for new accounts (90 days); billing required after free tier

**Resources:** Gemini API docs, AI Studio quickstart, Gemini 3 developer guide, pricing/limits FAQ

## Judging criteria

| Criterion | Focus |
|-----------|--------|
| **Application of Technology** | How well chosen model(s) are integrated |
| **Presentation** | Clarity of pitch, demo, and materials |
| **Business Value** | Impact and fit for real business use |

**RelAI angle:** Emphasize multi-agent orchestration, human-in-the-loop approvals, and enterprise networking utility — not “just a chatbot.”
